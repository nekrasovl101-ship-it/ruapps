RuApps — это веб-сайт-каталог приложений для iPhone по адресу nekrasovl101-ship-it.github.io/ruapps. Здесь написано, какие данные RuApps получает и что с ними происходит.

Вход через Google или Apple

Чтобы загружать приложения, можно войти через аккаунт Google или Apple. Вход проходит на странице самого Google или Apple — RuApps не видит и не получает ваш пароль.

После входа RuApps получает только:

  • ваше имя;
  • адрес электронной почты;
  • фото профиля (только для Google);
  • технический идентификатор аккаунта.

Эти данные используются только чтобы показать ваш аккаунт в настройках RuApps и разрешить загрузку приложений.

Где хранятся данные

Список «Мои приложения», выбранная тема и данные входа хранятся в браузере на вашем устройстве (localStorage). При входе через Google сервер RuApps один раз проверяет вход у Google и выдаёт сессию — сами данные аккаунта обычных пользователей на сервере не сохраняются.

Нажмите «Выйти» в настройках RuApps — и данные аккаунта удалятся с устройства. Также можно очистить данные сайта в настройках браузера.

Аккаунт разработчика

Если вы активируете аккаунт разработчика, сервер RuApps (на Cloudflare) сохраняет: имя, e-mail, ваш Telegram ID и имя пользователя в Telegram, дату активации. Это нужно, чтобы бот мог сообщать о проверке ваших приложений.

Загруженные IPA-файлы и иконки хранятся публично в GitHub (репозиторий ruapps-files), а их название, версия, Bundle ID, описание и ваше имя как разработчика показываются в каталоге RuApps. Удалить своё приложение можно в разделе «Мои загрузки».

Чтобы удалить аккаунт разработчика и данные о нём, напишите владельцу магазина (контакты ниже).

Мы не продаём и не передаём ваши данные третьим лицам.

Сторонние сервисы

  • GitHub Pages и GitHub Releases — хостинг сайта и файлов приложений. GitHub может вести технические журналы посещений (например, IP-адрес) по своим правилам.
  • Cloudflare Workers — сервер RuApps (вход, аккаунты разработчиков, загрузка приложений).
  • Telegram — бот для активации аккаунта разработчика и уведомлений о проверке.
  • Google Sign-In и Sign in with Apple — сервисы входа, работают по правилам Google и Apple.
  • DNS-профили в настройках — по желанию. Если вы установите профиль, запросы DNS будут идти к выбранному провайдеру (Cloudflare, AdGuard, Google или Quad9) по его правилам. Удалить профиль можно в Настройки → Основные → VPN и управление устройством.

Дети

RuApps не собирает данные специально о детях и не предназначен для сбора их персональных данных.

Изменения

Если политика изменится, новая версия появится на этой странице с новой датой.
